Tags

    1) action

    2) method="GET/POST/PUT/DELETE"

            1) GET - used to read data from backend
            2) POST - used to send data to backend
            3) PUT - used to update backend data
            4) DELETE - used to delete backend data
    3) name
            used to assign logical name to the form
            Ex.
                name="regForm"
                    where "regForm" is the logical name of the form

    4) onsubmit
            used to handle the submit event
            Ex.
                onsubmit="register()"
                    when ever we click submit button, automatically "register()" function will execute in 
                    JavaScript

    5) onreset
            used to handle reset event
            Ex.
                onreset="cancel()"
                    when ever we click cancel button, automatically "cancel()" function will execute in JavaScript

positions
*********
    css supports five positions
    1)relative
    2)absolute
    3)fixed
    4)sticky
    5)static

relative
********
    moving element from it's origin called as relative position

    Note : because of relative positions, other elements never effect in layout

z-index
*******
    z-index released in CSS3
    z-index, used to change the order of elements in stack
    Ex.
        z-index : 100;

absolute
********
    moving elements with respect to closest ancestor(parent) called as absolute position
    Ex.
        position: absolute;
        left:
        right:
        top:
        bottom:

    Note : because of absolute position, other elements will effect in layout

what are the differences between relative position and absolute position ?

**********************************************************************************************************
                    relative position                       absolute position
**********************************************************************************************************
1) moving element from starting                         moving element with respect to closest
   position called as relative position                 parent(ancestor) called as absolute position

   syntax.                                              syntax.
        position: relative;                                 position: absolute;

2) because of relative position                         because of absolute position, other elements
   other elements never effects                         will effect in webpage
   in webpage
**********************************************************************************************************

            position: fixed;

            right :
            top :
            bottom :

******
